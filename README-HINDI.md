# Apni website khud manage karne ka tarika

Koi coding nahi chahiye — sirf `data/` folder ki files edit karni hain.

## 1. Plans/price change karna
`data/plans.json` kholo, jo number ya price change karna hai wahi edit karo, save karo.

## 2. Photos add karna
1. Apni photo `assets/photos/` folder mein daalo (jaise `shop.jpg`)
2. `data/gallery.json` mein us photo ka naam likho: `"src":"assets/photos/shop.jpg"`

## 3. Social media links add karna
`data/settings.json` mein apne Facebook/Instagram/YouTube ke link daalo.

## 4. Blog ya naya area page add karna
Baad mein Claude se bologe to wo aapke liye naya page bana dega — bas content bata dena.
